# Aftertone — September 8 UI concepts

The user requested blocky 1990s computer typography while keeping Aftertone's warm, fun retro branding. These seven Figma concepts explore that direction. Earlier flowing-logo screens are preserved and labeled superseded.

Figma typography: Press Start 2P wordmark, VT323 headings, Inter body, IBM Plex Mono labels. Cream/orange/gold/chocolate palette; window chrome and tactile buttons. Screens were visually inspected and a correction-row overflow fixed. These are illustrative design concepts, not interactive prototypes or evidence of live provider integration.
