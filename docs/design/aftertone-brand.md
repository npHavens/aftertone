# Aftertone — retro and fun brand direction

Updated: September 8, 2026. Product name and retro/fun direction chosen by the user. Latest revision: try a blocky 1990s computer font while retaining the warm palette.

**Aftertone** · **Your music, rediscovered.**

The personality is a friendly 1990s desktop music application with mixtape warmth: pixel lettering, window title bars, chunky outlined controls, warm paper surfaces and clear status labels. Keep sound/rhythm motifs format-neutral. Avoid disc silhouettes as the primary logo, generic AI sparkles, neon cyberpunk styling, and an all-black dashboard.

## Logo

Historical generated concept: [1970s Aftertone logo](../../public/brand/aftertone-logo-concept.png). Preserve this exploration, but the current UI should try a blocky pixel wordmark instead of using the flowing raster lettering. The new wordmark is typeset so it stays crisp at multiple sizes.

Before production release, create an optically corrected SVG master, one-color light/dark variants, a simplified ribbon app icon and favicon, and minimum-size/clear-space examples. Inspect at 24, 32 and 48 pixels. Keep provider logos official and visually separate from Aftertone branding. Name/domain/trademark availability has not been cleared or a domain registered.

## Tokens

| Token         | Value     | Use                                       |
| ------------- | --------- | ----------------------------------------- |
| `paper`       | `#FFF3D6` | Main canvas                               |
| `ink`         | `#35251E` | Text, outlines, offset shadows            |
| `orange`      | `#C64C2D` | Brand accents, large emphasis             |
| `orange-deep` | `#A83A22` | Primary button surface with cream text    |
| `mustard`     | `#F3B544` | Labels and highlight panels with ink text |
| `mint`        | `#B9D6BC` | Completed states with ink text            |
| `card`        | `#FFFAEB` | Surfaces                                  |
| `muted`       | `#70594B` | Supporting text                           |

Use **Press Start 2P** for short wordmarks/display labels, **VT323** for larger terminal-style headings, and readable sans-serif/monospace for UI text. Figma has these faces available. Self-host licensed fonts for local frontend use; retain their license. Keep the pixel face out of dense tracklists and long paragraphs. Fraunces and the flowing raster lettering belong to the earlier exploration.

Spacing: 4/8/12/16/24/32/48/64. Controls: minimum 44px targets. Border: 2px ink. Corners: 12–24px for cards, full radius for pills. Shadow: 4px 4px 0 ink; pressed controls shift by 2px and reduce their shadow. Paper texture, if introduced, stays very subtle and out of text-heavy areas.

## Voice and interaction

- Hero: “Your music, rediscovered.” Supporting copy: “Turn album photos into a playlist. Bring the favorites back.”
- Upload: “Drop your album photos here.” Secondary: “One cover per photo works best.”
- Review: “Looking like your kind of mix.” Uncertain matches: “A little help with this one?”
- Publish: “Make my playlist.” Partial outcome: concrete counts and next action, without celebratory false success.
- Future AI: one quiet “Playlists from your ideas — coming later” note, not a working control.

Use short, playful transitions (approximately 150–220ms) and a brief success flourish. Respect reduced motion; no continuous spinning, flashing, or animation that obscures progress. Pair color with labels/icons. Keyboard focus, readable contrast and screen-reader announcements remain release requirements.
